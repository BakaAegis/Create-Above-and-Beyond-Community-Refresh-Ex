# 永无止境：超越无界 - 整合包 1.18.2 版本

这是一个在原 **永无止境：超越常新（CABR）** 基础上进行任务线拓展的整合包，运行于 **Forge 1.18.2**。本整合包引入了 Mekanism，并通过一系列修改使其与机械动力主题良好契合。在此欢迎每一位挑战者，衷心希望你能在 Minecraft 的游戏世界中尽情徜徉！

承接原有的抵达月球任务线，整合包新增了一系列飞向星空的指引——从空间站爆破、超速聚变，到输入机器码，从月球通往比邻星的道路将一步步向你展开。

### 发现新的挑战

度过缓慢却催人奋进的初期后，随着第一个主要产物实现完全自动化，发展的步伐开始加快。交错的传送带网络、搅拌与清洗水晶、控制爆炸、染色物质变化、向矿车发射激光、处理数字……种种并不简单却新奇的自动化任务等你挑战。

作为额外内容，化学研究与嬗变将带你发现独属于你的世界种子的秘密配方！

### 贸易和专精

买卖各种物品是整合包中显著改变游戏体验的机制。选择职业并完成差事，你就能购买自己偏好的资源，而无需从事烦人的苦工。交易机制可通过任务界面访问，并支持精巧的自动化。

### 额外的努力

整合包添加了大量方块、物品和流体，并通过自定义脚本为机械与材料提供了新的交互方式。此外，部分模组获得了新纹理，使整体风格更加协调统一。

### 兼容性

本整合包与原 **永无止境：超越常新（CABR）** 的存档兼容。
