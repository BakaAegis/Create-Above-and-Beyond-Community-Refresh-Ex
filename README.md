# 永无止境：超越无界 整合包 1.20.1 版本

> [!IMPORTANT]
> 本整合包为 **Create: Above and Beyond Community Refresh（CABR）** 的社区二次创作版本。请勿将本项目相关问题反馈至原 CABR 制作组。

这是一个在原 **永无止境：超越常新（CABR）** 基础上进行任务线拓展，并迁移至 **Minecraft 1.20.1** 的整合包，运行于 **Forge 47.4.23**。本整合包在保留机械动力核心体验的同时，引入了 Mekanism 深度适配、太空探索、应用能源计算、机器编程等丰富内容。在此欢迎每一位挑战者，衷心希望你能在 Minecraft 的游戏世界中尽情徜徉！

### 飞向星空与自动化新篇

承接原 CABR 的自动化流程，本整合包新增了多阶火箭、引导计算机、燃料系统与目的地维度。从发射第一枚火箭，到编写机器码控制复杂产线，通往比邻星的道路将一步步向你展开。

### 深度科技联动

Mekanism 内容经过大幅重构，并与 Create 紧密适配，实现了化学处理与机械自动化的深度融合。同时加入 Applied Energistics 2、ProjectRed、Thermal、Tinkers' Construct 等科技路线，为你提供多样化的自动化方案与全新的挑战。

### 全新的挑战与内容

基于原 CABR 流程扩展的 FTB Quests 任务线，带来了大量新奇而富有挑战的自动化任务。自定义配方、机器、战利品表、语言文件、纹理与兼容性修复，均已针对 1.20.1 模组环境调整。额外的探索、交易、建筑、存储和便利性内容，让你的世界更加丰富多彩。

### 安装与兼容性

- Minecraft 版本：**1.20.1**
- 模组加载器：**Forge 47.4.23**
- 整合包内模组已经过专门调整，请勿自行更新或替换模组。因更改或新增模组导致的问题，请勿提交至 issue。

本分支对 1.18.2 版本的旧存档提供部分兼容，但可能出现生产线运行异常，需要手动调整；不保证对 1.18.2 版本 CABREx 存档的完全兼容。

### 当前状态

1.20.1 分支目前处于 pre-release 测试阶段。火箭流程、引导计算机、计算矩阵、汇编指令装配及相关任务识别均已完成迁移验证。最终稳定版发布前，仍需进一步实机测试。
